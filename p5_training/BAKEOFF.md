# Sunday morning bake-off protocol

1. Code freeze for Track A demo path before or immediately after bake-off — don't merge mid-bake-off.
2. Same object set, same staging marks, same lighting.
3. Warm up: 2 unscored practice trials each (optional).
4. **Scripted:** 10 scored trials. Record Y/N + failure mode (miss / drop / wrong place).
5. **MolmoAct 2:** 10 scored trials. Same sheet. Serve winning checkpoint from Modal (action chunks).
6. Higher success count wins. Tie → prefer scripted (reliability for judges).
7. Winner becomes the Skill in the 5-minute demo. Document result in `runs/bakeoff_YYYYMMDD.md`.
8. Three full rehearsals of the exact demo after decision. Then hard freeze.
